# 🪵 工廠木工機台預約與排隊系統 (Web App)

本專案為專門給手機使用的工廠木工機台排隊與時段預約系統，提供 1:1 還原 AppSheet 介面外觀與自動化流程，資料庫直連 **Supabase PostgreSQL** 雲端資料庫，支援多人即時同步。

---

## 📱 核心功能特色

1. **Email 驗證與自動記住登入**：
   - 首次進入輸入修課名單 Email 驗證身分，並自動持久化登入狀態。
   - 頂部提供 🚪 快速登出按鈕。

2. **四大機台即時狀態看板 (Tab 1: 機台列表)**：
   - 帶鋸機、推台鋸、圓鋸機、自動刨木機。
   - 🟢 空閒 (`#E8F5E9`)：開放新增預約 / 排隊。
   - 🔴 使用中 (`#FFEBEE`)：機台使用中，不可隨意結束他人使用。
   - 🟡 等候報到 (`#FFF8E1`)：叫號等候報到中，顯示下一位同學姓名。

3. **我的預約與動態前拉叫號 (Tab 2: 我的預約)**：
   - **開始/結束使用**：依預約 ID 精準啟動（▶）與結束（⏹）。
   - **現場排隊提早結束自動前拉**：前一位結束時，全隊列時間自動前拉貼齊當前時間，第一位自動轉為「等候報到」，機台轉為黃色並推播叫號！
   - **清除歷史紀錄**：底部一鍵「🗑️ 清除已完成預約紀錄」，直連 Database 永久清理已完成/已取消資料。

4. **智慧預約時段矩陣 (Tab 3: 課程場次 & Tab 4: 預約設定)**：
   - **開課前 24 小時**：開放「時段預約」，矩陣動態根據課程時段生成 10 分鐘 Slot (`○` 可選、`●` 選定、`■` 已占用)。
   - **開課進行中**：開放「現場排隊」，即時依現有隊列智慧推算開始時段。
   - 支援「自動模式」（週三 09:00~12:00）與「手動模式」（自由指定上課時段）。

## 🌐 免費發布至 GitHub Pages (線上手機使用)

只要將本專案推送到 GitHub Repository，並開啟 **GitHub Pages**，任何人都可以直接在手機瀏覽器開啟使用！

### 步驟：
1. 進入 GitHub 專案倉庫 ➔ 點擊 **Settings**。
2. 點擊左側選單 **Pages**。
3. 在 **Build and deployment** 下方：
   - Source 選擇：`Deploy from a branch`
   - Branch 選擇：`main` / `root`
   - 點擊 **Save**。
4. 約 1~2 分鐘後，即可獲得專屬線上網址（例如 `https://<你的帳號>.github.io/<專案名稱>/`），手機開啟後可「加入主畫面」當作原生 App 使用！

## 💻 本地端運行

雙擊專案目錄下的 `啟動本地測試網頁.bat` 或執行：
```bash
node server.js
```
並在瀏覽器開啟 `http://localhost:3000`。
